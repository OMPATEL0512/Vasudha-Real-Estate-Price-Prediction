> **AI/ML-Powered Property Valuation & Micro-Market Intelligence Platform for Ahmedabad, Gujarat**

| Feature | Details |
|:---|:---|
| 🤖 **ML Engine** | `scikit-learn` log-linear fixed-effects regression — **R² = 0.9996** |
| 🗺️ **Coverage** | **29+ Ahmedabad micro-markets** (Bodakdev, Ambli, Thaltej, Shela…) |
| 📅 **Historical Data** | Real price trends **2020–2026** with interactive SVG charts |
| 🏘️ **Property Types** | Apartment/Flat (1.0x) & Tenement/Duplex (1.28x land premium) |
| 🔐 **Auth System** | Email OTP verification via Gmail SMTP |
| 🗄️ **Database** | MongoDB primary + SQLite fallback with auto-sync |
| 📧 **Reports** | Gold & midnight-navy HTML property valuation email reports |
| 📈 **Projections** | 5-year compounding appreciation forecasts per locality |
| 🌐 **Dual Frontend** | Flask app (`frontend.py`) + Standalone HTML (`vasudha-real-estate.html`) |

### 🔌 API Endpoints

```
POST  /api/auth/register          →  Initiate registration with Email OTP
POST  /api/auth/verify-otp        →  Verify OTP & create account
POST  /api/auth/login             →  Sign in
POST  /api/auth/forgot-password   →  Send password reset OTP
POST  /api/auth/reset-password    →  Set new password
GET   /api/localities             →  All 29+ Ahmedabad localities & metadata
GET   /api/locality/<name>        →  Locality detail + historical price points
POST  /api/estimate               →  ML valuation + 5-year projections
```
